# Project learnings

- marketing/SaaS skew across 69 cards | CLAUDE.md and VOICE.md originally prompted cards to target 'a B2B SaaS marketer' and 'ideally on marketing copy' | stripped marketing directives from CLAUDE.md/VOICE.md and systematically rewrote stealIt slides to focus purely on general prose craft, essays, observation, and storytelling
- triad and banned word linter flags during card drafting | lint_cards.py strictly enforces 60-word stealIt limit, bans triads ('X, Y and Z'), and flags adjectives/verbs like 'elevate' | refactored phrasing to paired items and concrete physical verbs
- Ollama gemma3:4b bare list format error | when prompt requested a bare JSON list under format: "json", gemma3:4b returned an empty `{}` | updated prompt to request an explicit JSON root object `{"quotes": [...]}`
- EPUB chapter filter false positives | substring check `skip in low` with `"about"` dropped all chapters of books with "about" in the title (e.g. Murakami's *What I Talk About When I Talk About Running*) | switched to exact stem matching and regex boundary patterns
- Mac sleep halts unattended Ollama mining | macOS power management sleeps system after idle timer during long scripts | invoked background automation via `caffeinate -dimsu` to keep Apple Silicon CPU/GPU awake
- rclone ls path parsing failure | `rclone ls` outputs byte size prefix before file path causing 'directory not found' | parsed clean path via regex `^\s*(\d+)\s+(.+)$`
- EPUB metadata naming mismatches | filenames alternate between Title-Author and Author-Title | parsed authoritative `dc:title` and `dc:creator` tags directly from `content.opf` inside the EPUB zip
- Android SDK location failure in Gradle | `./gradlew` fails with `SDK location not found` | set `sdk.dir=/Users/apple/Library/Android/sdk` in `local.properties` and pointed `JAVA_HOME` to Homebrew OpenJDK 17
- Single-page thematic UX vs folders | nested folder menus hide quotes and create navigation friction | flattened 1,871 quotes into a continuous single-page stream segmented by 6 evocative thematic horizons with live in-place tag filtering
- Android app missing quote bank option | MainActivity was hardcoded exclusively to cards.json | added dual-mode switcher (Daily Cards vs Quote Bank) and QuoteBank loader with 2-slide reading and Surprise button
- Widget shelf explanation truncated and tapping skipped to next book | quote and explanation were crammed into one view with maxLines="3" and tap zones covered full view | split Shelf Spark into 2 slides (The Line -> Scene Context with full height) and updated tap logic
- Dark mode low contrast on pills and headers | mode toggle pills and badges lacked night-mode color declarations and used paper color on sheet background | defined semantic pill_active_bg/text and shelf_badge drawables with explicit light/dark values
- Widget shelf cycling quotes on tap | step() incremented quote index on the widget instead of restricting home screen to single daily quote | locked widget to todayIndex and configured tap to flip only between The Line and Scene Context
- Lackluster quote bank explanations | initial extraction used 1-sentence micro-glossary verbs without narrative setting | expanded explanations to 2-3 sentences setting book circumstance, human dilemma, and emotional stakes
- Prototype Slide 1 repeated quote instead of job | cards.json stores job in "job" key while template checked undefined "hook" and fell back to quote | parsed card.job with removePrefix("How to ") matching Android Slide.hookTitle
- Decorative milieu filler & Paragraph 2 redundancy in LLM explanations | forcing physical setting prompts the LLM to invent irrelevant fake weather/actions, and re-explaining danger makes Paragraph 2 redundant | instructed prompt to focus Paragraph 1 directly on the character's psychological defense posture unless the physical environment IS the danger, and dedicated Paragraph 2 to the author's intent and universal human truth without word count chokeholds
- Widget & App long explanation stretching and clinical tag clutter | dumping long explanations into a single card caused infinite vertical stretching in preview, and badges like 'SCENE CONTEXT' felt clinical | segregated Paragraph 1 and Paragraph 2 cleanly, added dynamic sentence chunking (≤60w in widget, ≤85w in app) across 3-5 slides, and replaced clinical tags with clean progress counters (e.g. 1 OF 4)
- Daily alternating dual-mode rotation and browse state persistence | users want effortless daily rotation between curated craft cards and personal shelf quotes, while ensuring manual browsing selections stick | implemented parity-based daily alternator (Cards <-> Shelf) keyed to epoch day offset with startFrom retention across both collections for widget and app readers
- Literary slide badges vs clinical tags and preview overflow clipping | clinical tags like 'SCENE CONTEXT' feel dry, while removing tags entirely creates disorientation; also fixed-height web cards clipped overflow whereas Android used native ScrollViews | introduced evocative badges ('THE LINE' -> 'THE PREDICAMENT' -> 'THE MIRROR') across app and widget, named collections 'Prose Craft' and 'Shelf Sparks', and added overflow-y: auto in web prototype to mirror native Android behavior
- GitHub Pages deployment for APK download & mobile web app | GitHub Pages easily serves both the responsive static web app (index.html) and Android APK (marginalia.apk) from /docs with .nojekyll to bypass Jekyll parsing, enabling immediate web preview and direct downloads on mobile Chrome without third-party hosting
- Widget fixed-height truncation vs app scrolling | 4x2 Android widgets and preview cards have strict unscrollable ~150dp text bounds that slice lines when word counts exceed 50w | capped widget slide chunks at 42 words max in CardWidgetProvider.kt, increased card preview height to 290px, and added dynamic text auto-scaling (0.96rem down to 0.78rem)
- Catalog UI sensory overload vs anthology design | dumping uncollapsed multiline notes, harsh border callouts, and developer debug tabs created visual noise for web readers | separated UI into pure 'Daily' and 'The Library' tabs, replaced harsh callouts with collapsible '▾ Companion Note' accordions, and hid internal widget simulator behind ?debug=widget
- Duplicate closing header tags breaking DOM & desktop centering | duplicate `</div></header>` in template.html prematurely closed `.wrap`, throwing all views into unconstrained `<body>` which stretched 1920px wide across desktop monitors and misaligned header elements | removed duplicate closing tags, set `.wrap` to `max-width: 580px; width: 100%; margin: 0 auto;`, and centered `body` flexbox
- HTML `[hidden]` attribute overridden by author `display: flex` rules | CSS rules like `.bank-container { display: flex; }` have higher specificity than user-agent `[hidden]`, causing Daily, Widget, and Library views to render stacked simultaneously on the page | added `[hidden] { display: none !important; }` and updated `switchView()` to explicitly set `style.display = 'flex' | 'none'`
- Mobile page scroll lock from `overscroll-behavior-y: contain` | `.slide` defined `overscroll-behavior-y: contain` across the full viewport, capturing touch events and preventing vertical scrolling of the window | changed to `overscroll-behavior-y: auto`, tuned mobile slide height to 380-480px, and enabled `-webkit-overflow-scrolling: touch`
- Local vs. public GitHub preview environment separation | public web app visitors do not need developer widget simulators, but local dev needs it for rapid iteration | added automatic hostname check (`location.hostname === 'localhost' || '127.0.0.1'`) that renders the `🔲 Widget` tab locally while keeping it completely hidden on GitHub Pages
- Widget preview scroll clipping & text truncation | `.widget-card-sim` used `align-items: center` with `overflow-y: auto`, causing the flex-center overflow bug where top lines scrolled into unreachable negative space | wrapped widget text in `.w-body-container` (`justify-content: flex-start; overflow-y: auto;`), eliminated center clipping, and introduced dynamic proportional font scaling (`getWidgetQuoteSize` and `getWidgetTextSize`)
- Widget slide count explosion vs chunk sizing | aggressive 42-word chunk limit split 300-word 2-tier explanations into 10 fragmented micro-slides on the widget, requiring 10 taps to read one quote | adjusted chunk limit to 80 words, consolidating thoughts into 3 to 5 cohesive slides max (Line, Predicament, Mirror) mirroring the 5-slide cadence of Craft Cards
